# RunRTOS 公共头文件

公共头文件按依赖层级组织，应用代码必须使用完整的 `runrtos/...` 路径。

| 目录 | 职责 |
| --- | --- |
| `core/` | 编译器适配、基础类型、配置和断言 |
| `runtime/` | 内存、字符串和格式化运行库 |
| `kernel/` | 调度、线程、同步、队列和软件定时器 |
| `arch/` | 架构无关的移植接口 |
| `drivers/` | 设备模型，以及按总线或设备类别拆分的驱动接口 |

依赖只能从下层指向上层方向使用：`core -> runtime -> kernel -> arch -> drivers`。
