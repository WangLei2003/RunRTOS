| 文档 | 约束内容 |
| --- | --- |
| [architecture.md](architecture.md) | 分层、目录、依赖方向和模块边界 |
| [coding-style.md](coding-style.md) | 文件和标识符命名、类型与接口规则 |
| [implementation-rules.md](implementation-rules.md) | 标准库、编译器扩展、断言和可移植性规则 |

规范性词语“必须”不可被局部实现绕过；若确需例外，必须新增 ADR 并在评审中明确
例外范围、理由和退出条件。
