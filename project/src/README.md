# RunRTOS 源码目录

源码目录与公共头文件采用相同的分层，并在组件内部继续按职责拆分。

| 目录 | 职责 |
| --- | --- |
| `core/` | 基础类型状态和断言实现 |
| `runtime/` | 内存、字符串、格式化子模块 |
| `kernel/` | 调度器、同步机制及私有内核接口 |
| `arch/` | Cortex-M 启动、异常入口、上下文切换和链接脚本 |
| `drivers/` | 设备框架，以及 GPIO、UART、SPI、I2C 实现 |
| `bsp/` | 具体开发板的时钟、引脚、设备装配和启动代码 |
| `applications/` | 可裁剪的示例与诊断应用 |
| `components/` | Shell 等可选组件 |

私有头文件必须留在对应 `src` 子目录中，不进入公共包含目录。
