## 已确认决策

- 下一阶段主线：先完成 0.1 软件，再统一上板验收。
- USART1：Shell 优先；心跳日志通过 `demo start|stop` 启停。
- 板端自检：24C02 和 25Q16 采用可逆读写。
- 驱动异步：UART、SPI、I2C 全部使用真实中断异步；DMA 延期。
- W25Q16：测试时从 allocator 临时申请 4 KiB 备份首扇区；不足时 `SKIP`。
- Git：本轮先初始化本地仓库并建立阶段提交，GitHub 登录和推送延期。

## 关键设计决策

- 公共 API 保持现有驱动签名，新增 API 统一返回 `RunStatus` 并记录上下文、
  所有权、超时与并发约束。
- 同一驱动实例只允许一个未完成异步传输；占用时返回
  `RUN_STATUS_BUSY`，完成回调在 ISR 上下文执行且只执行一次。
- Shell 使用静态命令表，不支持运行时 ELF 装载、引号或转义。
- 自检不得假定 25Q16 扇区为空；正常完成时恢复原始 4 KiB 数据。
- 固件运行时继续禁止 libc、CMSIS、ST HAL 和第三方运行时。
- 主机测试端口可以使用宿主 OS 的 fiber API，但不会链接进固件。
